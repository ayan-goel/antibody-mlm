# 05 · Data

Three data tiers: the **pretraining corpus** (OAS VH), the **metadata sidecars** that carry biological priors into the masking strategies, and the **benchmark datasets** used for downstream evaluation.

## Pretraining corpus

**`data/processed/oas_vh_500k.jsonl`** — ~500K human heavy-chain (VH) variable-region sequences from the **Observed Antibody Space (OAS)**. One JSON object per line:

| Field | Type | Notes |
|-------|------|-------|
| `sequence` | str | VH amino acids, uppercase |
| `cdr1_aa`, `cdr2_aa`, `cdr3_aa` | str | CDR **substrings** of `sequence` (added by `scripts/annotate_cdrs.py`) |
| `v_call`, `j_call` | str | IMGT allele calls, e.g. `IGHV1S45*01`, `IGHJ4*01` |

CDRs are stored as raw substrings, not IMGT-numbered indices. At load time `data/dataset.py` locates them in the sequence (forward search for CDR1/2; rightmost match for CDR3, which anchors near the C-terminus) to build the per-residue `cdr_mask` ∈ {0,1,2,3}. Sequences are filtered to `min_length ≤ len ≤ max_length` (80–160 for VH) and to canonical amino acids.

**Loading & split.** `data/dataset.py:AntibodyDataset(data_path, tokenizer, max_length, coords_path=…, paratope_path=…, germline_path=…)` loads the JSONL plus any sidecars. The train/eval split is a seeded `random_split` (`train_split=0.9`). **At evaluation time the split is pinned to `EVAL_SPLIT_SEED=42`** regardless of a model's training seed, so every model is scored on the identical held-out set.

**Paired variant.** `data/processed/oas_paired_500k.jsonl` carries `sequence_heavy`/`sequence_light` plus per-chain `cdr*_aa_*` and `v/j_call_*`, loaded by `data/dataset_paired.py`. Used only by the (not-in-table) `multispecific`/`hybrid_paired` runs.

## Metadata sidecars (`data/structures/*.pt`)

`torch.save`'d **`list[dict | None]`** aligned 1:1 with the JSONL (entry `i` ↔ record `i`; `None` if generation failed/filtered). Load with `torch.load(path, weights_only=False)`. The dict keys are exactly the `metadata` keys the masking strategies consume ([03](03-masking-strategies.md)).

| File | Key | Tensor | Feeds | Generated by |
|------|-----|--------|-------|--------------|
| `oas_vh_500k_paratope.pt` | `paratope_labels` | `Float(L,)` ∈ [0,1] | `interface`, `intersection`, hybrids | `scripts/compute_paratope_labels.py` |
| `oas_vh_500k_germline.pt` | `germline_labels` | `Float(L,)` ∈ {0, 0.5, 1} | `germline`, `intersection`, hybrids | `scripts/compute_germline_labels.py` |
| `oas_vh_500k_igfold.pt` | `knn_indices` | `Int16(L, 32)` | `structure`, hybrids | `scripts/predict_structures*.py` (IgFold) |

- **paratope** labels are soft probabilities derived from a `P(paratope | amino acid, CDR region)` frequency table built from the TDC SAbDab_Liberis labels (IMGT/ANARCI region assignment), then applied per residue.
- **germline** labels compare each residue to a per-(V-gene, J-gene) **consensus** built from the corpus itself; `0` = matches germline, `1` = somatic mutation, `0.5` = CDR3 junction or low-confidence (genes with too few sequences fall back to 0.5).
- **igfold** stores the 32 nearest 3-D neighbors per residue from an **IgFold-predicted** structure; the `structure` strategy uses the first `k_neighbors` of them (and `min_seq_separation` to drop sequence-adjacent ones).

> A legacy `oas_vh_500k_coords.pt` (ESM2 contact-map kNN) predates the IgFold sidecar. The README/GUIDE prose still says "ESM2 contact-map kNN," but the `structure*` **configs point at `oas_vh_500k_igfold.pt`** — IgFold is what the reported experiments use.

Paired sidecars (`oas_paired_500k_{paratope,germline,interface}.pt`) add `interface_labels` for the VH–VL interface; produced by `scripts/compute_multispecific_labels.py`.

## Benchmark datasets (`data/benchmarks/`)

External, curated datasets used **only for downstream evaluation** (never for pretraining). The metric math lives in [07-evaluation-and-metrics](07-evaluation-and-metrics.md); this is the data side.

| Loader | Source | What it provides | Used by |
|--------|--------|------------------|---------|
| `paratope.py` | TDC **SAbDab_Liberis** | per-residue binary paratope labels (antigen contact ≤ 4.5 Å), train/val/test splits | paratope probe; paratope frequency table |
| `contact_map.py` | **SAbDab** real X-ray Cα coords (`data/structures/sabdab_liberis_coords.pt`, built by `scripts/build_sabdab_real_coords.py`) | Cα coordinates → binary contact matrices at 8 Å; split 60/20/20 **by PDB** | contact-map probe; attention–contact analysis |
| `structure_probe.py` | **AB-Bind** PDBs (`data/ab_bind/pdbs/`) **+ SAbDab** coords | pairwise Cα distances (regression targets) | structure probe |
| `developability.py` | TDC **TAP** (242 antibodies, VH used) | 5 developability targets: `CDR_Length`, `PSH`, `PPC`, `PNC`, `SFvCSP` (z-scored) | developability probe |
| `ab_bind.py` | **AB-Bind** (Sirin et al. 2016) | wild-type/mutant sequence pairs + experimental ΔΔG, grouped by complex | zero-shot mutation benchmark |
| `binding.py` | **CoV-AbDab** (SARS-CoV-2 neutralization) | binary neutralization labels | binding probe — **implemented but not in the comparison table** (no `binding_probe.yaml` on disk, no `ds_binding_*` columns) |

`sabdab_liberis_coords.pt` entries are dicts: `{id, pdb_id, chain, sequence, coords_ca: Float(L,3), paratope: [positions]}`.

## File-format recap

- **JSONL**: one record per line; `utils/io.load_jsonl` → `list[dict]`.
- **`.pt` sidecars**: `list[dict|None]`, length = corpus size, indexed by record number.
- **`paper/figures/_canonical_region_cache.npz` / `_fingerprints_cache.pkl`**: figure-only caches (precomputed region boundaries / per-strategy fingerprints) so figures render without a GPU — see [09-figures](09-figures.md).

## Caveats for the paper

- OAS CDR annotation is substring-based; insertions/deletions can occasionally defeat the match.
- Germline labels for rare V/J genes fall back to 0.5 (uncertain).
- IgFold can fail on unusual sequences → `None` sidecar entries (those samples fall back to uniform masking for `structure`).
- Exact corpus count is ~497K (filename rounds to "500k"); confirm against `wc -l` if a precise N is needed for the paper.
